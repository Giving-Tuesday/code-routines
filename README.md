# code-routines
Git history of prompts used in Claude Code routines.

## Plugins

- `code-routines` runs Claude Code routines and scheduled tasks.
- `gt-charts` turns an image of a chart into a gt-charts example notebook that Databricks can import. Use its `chart-to-notebook` skill.

To install a plugin in Claude Code, add this marketplace and then install the plugin by name:

```text
/plugin marketplace add Giving-Tuesday/code-routines
/plugin install gt-charts@code-routines
```
